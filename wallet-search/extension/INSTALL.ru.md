# Wallet Search 0.6.0

1. Распакуйте обновление в папку установленного расширения или используйте готовые папки сборки `dist/chrome-extension` и `dist/etoro-wallet-search-extension`. Обе обновляются при каждой сборке.
2. В `chrome://extensions` обновите **eToro Wallet Search**, затем обновите Wallet. В панели должна быть версия **v0.6.0**.
3. При открытии кеш показывается сразу. Новые и незавершённые операции проверяются автоматически в фоне; при первом запуске без кеша история загружается один раз. Фильтры: текст, даты, направление, тип, статус и сумма. **Найти** догружает запрошенные недостающие периоды. Ошибка фонового запроса сохраняет данные и не открывает экспорт.
4. **Обновить** и число загруженных операций находятся сверху. Значок вращается во время загрузки; повторное нажатие заблокировано до её окончания. Снизу показано только число найденных операций. **Выключить расширение** убирает текущую панель, отменяет загрузку и сохраняет кеш. После перезагрузки страницы расширение снова активно.
5. **Статистика** снизу панели открывается кликом либо Enter/Пробелом. Выбирается только **год**; итоговые суммы относятся ко всему году. Месячные столбцы показывают подробности при наведении или фокусе. **Платежи**, **Переводы** и **Все** разделены. Категории и статусы включаются отдельно; ожидающие и отменённые не увеличивают проведённые суммы.

Аккордеон плавно открывается и закрывается примерно за 0,3 секунды; стрелка поворачивается синхронно. Быстрый повторный клик меняет направление текущей анимации. При системной настройке уменьшения движения открытие и закрытие происходят сразу.

## Локальный кеш

Операции сохраняются локально, включая новые и ожидающие. Автообновление идёт с последней проверенной даты либо с самой старой ожидающей/неизвестной операции в пределах 42 дней. Старые пробелы истории загружаются только по запросу поиска/статистики. Пограничная страница API может содержать старые строки; следующие архивные страницы повторно не читаются. Более старые ожидающие сохраняют статус. 42 дня — наша граница автопроверки, а не срок проведения eToro. **Обновить** перечитывает выбранный диапазон поиска полностью. Счета, валюты и часовые пояса разделены. **Очистить локальный кеш** удаляет текущую локальную комбинацию; новое открытие Wallet может загрузить историю снова.

Известный сервер `prodfileexportwe.blob.core.windows.net` входит в разрешения установки вместе с eToro. Другой сервер Azure Blob может потребовать согласия на конкретный домен. Доступа к произвольным сайтам нет; новый поставщик экспорта потребует изменения расширения.

Поддерживаются все 20 языков из текущего меню eToro, включая арабский с направлением справа налево. Панель, popup и справка используют одну локализацию. Месяцы, числа и валюты форматируются по выбранному языку.

Тип и статус читаются из обычной истории eToro. Если доступен только TSV, неизвестные значения не угадываются и помечаются как неизвестные. Финансовые действия и изменения настроек аккаунта не выполняются.

## Tampermonkey

Вместо расширения можно заменить содержимое скрипта файлом `etoro-wallet-search.user.js`, сохранить и обновить Wallet. Старые данные сохраняются через локальное хранилище Tampermonkey. Используйте только один вариант установки одновременно.

До 200 000 операций и 32 МиБ за загрузку. Данные не отправляются на собственный сервер. Большие списки используют виртуальную прокрутку.
