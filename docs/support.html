Support for eToro Wallet Search v0.6.0

Contact

chrome.ext.dev.contact@gorelenkov.dev

For privacy questions, licensing requests or anything containing private information, use email. For reproducible bugs and feature suggestions, open a GitHub issue using synthetic examples.

Do not post real CSV/TSV files, IBANs, names, balances, credentials, signed export links or account screenshots in public issues. Start support requests with the extension version and a description; private account material is not needed for an initial report.

Installation

  1. Download the extension ZIP from Releases and extract it.
  2. Open chrome://extensions, enable Developer mode, select “Load unpacked”, and choose the folder containing manifest.json.
  3. Sign in to eToro, open Wallet and select a currency account.
  4. Keep an older Tampermonkey copy disabled while using the extension.

The panel is missing

Reload Wallet after installing or updating the extension. Open the extension popup and choose “Show panel” or “Enable search”. Check that you are on a Wallet account page and that Chrome allows the extension on eToro.

History is not loading

The normal path reads the existing signed-in Wallet listing. If it fails, cached records remain available. Use Refresh to retry. An interactive export fallback can open eToro’s export dialog. For another Azure export region, review the exact host displayed in the popup before granting it access. An expired session or an eToro redesign can prevent loading.

Refresh, cache and unfinished entries

Opening Wallet shows the local cache first, then checks forward from the latest verified date. Eligible pending or unknown entries are rechecked within a 42-day window. This is a recheck policy, not an eToro settlement deadline or a storage expiry. Older uncovered periods are requested when a search or yearly statistics needs them.

Delete cached history

“Clear local cache” removes the current account/currency/time-zone snapshot and its in-memory view. Other scopes must be cleared separately. “Disable extension” affects the current page instance and retains cached history; reloading can enable it again. Neither control deletes eToro records.

Report a security problem privately

Email chrome.ext.dev.contact@gorelenkov.dev or use GitHub private vulnerability reporting. Describe the issue using synthetic data. Avoid financial account details or active credentials.

Supported languages

English, Spanish, Italian, German, Russian, Simplified Chinese, French, Arabic, Traditional Chinese, Polish, Dutch, Norwegian Bokmål, Portuguese, Swedish, Czech, Danish, Romanian, Vietnamese, Finnish and Greek. The panel follows the selected eToro language. Dates use the browser’s local calendar and time zone.

License & commercial requests

Noncommercial use follows PolyForm Noncommercial 1.0.0. For other commercial use, contact the publisher before proceeding. Approval and any fees or revenue participation require a separate agreement.
